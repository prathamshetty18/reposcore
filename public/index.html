Audit Methodology & Specifications

Transparent distinction between mathematical/verifiable rules and advisory open-weight machine assessments.

SPEC-01 // Deterministic Rules Engine

Static assertion checks evaluated against verified repository tree metadata and raw artifacts. Identical inputs produce identical, reproducible findings every time with zero hallucination.

  • Inspects README structure, OSI license headers, CI pipelines, test harnesses, code of conduct
  • Binary pass/fail verdicts backed by concrete textual proof
  • Zero model dependency — always verifiable and offline capable
  • Sub-second execution profile
SPEC-02 // Provider-Agnostic AI Advisory

Executes all deterministic checks, augmented by an open-weight AI model (via Groq, OpenRouter, or local Ollama) for qualitative evaluation. All AI verdicts are marked advisory and never override deterministic findings.

  • Scores criteria from 0–5 with structured technical reasoning and actionable recommendations
  • 100% open-weight model weights — no closed proprietary black-box APIs
  • Strict schema validation; unscored criteria are explicitly isolated
  • Advisory layer only — human reviewer holds final authority

[AUDIT NOTICE] AI evaluations are advisory. Rule results are deterministic and verifiable.
